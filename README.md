## Mathematical Foundations of the Canvas Engine

The background canvas (`#math-field` in [`canvas.js`](file:///home/aryanm/dev/portfolio/js/modules/canvas.js)) executes a real-time mathematical simulation decoupled from DOM rendering.

### 1. Damped Wave Mechanics & Harmonic Motion (Hero Visual)
The hero section visualizes a traveling wave generated by the projection of uniform circular motion on a phase circle of radius $r = 0.5 \cdot \text{height}$ rotating at angular frequency $\omega = 1.5\,\text{rad/s}$:

$$y(x, t) = -r \cdot e^{-\gamma (x - x_0)} \cdot \sin(\omega t - k(x - x_0))$$

- **Spatial Decay Envelope**: $\gamma = \frac{3.5}{0.6 \cdot W}$ exponentially attenuates the wave amplitude across screen width $W$.
- **Wavenumber Factor**: $k = 0.015\,\text{rad/px}$ sets the spatial frequency.
- **Responsive Geometry**: On mobile devices ($W \le 768\,\text{px}$), the system smoothly rotates the coordinate frame $90^\circ$ to propagate vertically down the viewport ($e^{-\gamma y}$).

---

### 2. Anisotropic Distance Metric & Magnetic Grid Warping
Standard radial displacement based on Euclidean distance ($L_2$) creates an artificial circular spotlight artifact. To blend magnetic repulsion naturally with the rectangular Cartesian grid, the engine employs a hybrid anisotropic metric combining Manhattan ($L_1$) and directional Euclidean norms:

$$d(\Delta x, \Delta y) = \frac{1}{2}\sqrt{(0.75\,\Delta x)^2 + (1.15\,\Delta y)^2} + \frac{1}{2}(|\Delta x| + |\Delta y|)$$

Points within the influence horizon $R = 320\,\text{px}$ experience quadratic elastic displacement:

$$\text{factor} = \left(1 - \frac{d}{R}\right)^2$$

$$\vec{p}' = \vec{p} + \Delta\vec{p} \cdot \text{factor} \cdot 0.22$$

Grid lines, basis vectors, and the unit parallelogram are subdivided into multi-point segments and warped dynamically around the cursor.

---

### 3. Dynamic Linear Transformations & Matrix Geometry (3Blue1Brown Inspired)
As the user scrolls into the projects and machine learning sections, a smoothstep peak envelope activates a dynamic 2D linear transformation:

$$\mathbf{A}(t) = \begin{bmatrix} a & b \\ c & d \end{bmatrix} = \begin{bmatrix} s_x \cos\theta - \sigma_y \sin\theta & -\sin\theta \\ s_x \sin\theta + \sigma_y \cos\theta & \cos\theta \end{bmatrix}$$

where time-dependent parameters are modulated by scroll distortion:
- **Shear**: $\sigma_y = 0.5 \sin(1.35t) \cdot \text{distortion}$
- **Non-Uniform Scale**: $s_x = 1 + 0.3 \cos(1.1t) \cdot \text{distortion}$
- **Rotation**: $\theta = 0.2 \sin(0.75t) \cdot \text{distortion}$

#### Visualized Geometric Elements:
1. **Basis Vectors**: Shows the landing position of unit vectors $\mathbf{\hat{i}} = \begin{bmatrix} a \\ c \end{bmatrix}$ (green `#2bff88`) and $\mathbf{\hat{j}} = \begin{bmatrix} b \\ d \end{bmatrix}$ (cyan `#38bdf8`).
2. **Determinant & Unit Area**: A translucent green parallelogram spans $(0,0) \to \mathbf{\hat{i}} \to (\mathbf{\hat{i}} + \mathbf{\hat{j}}) \to \mathbf{\hat{j}}$. Its area represents the determinant $\det(\mathbf{A}) = ad - bc = s_x$, showing how space scales under linear mapping.
3. **Live Matrix Typography**: A grid-anchored matrix bracket renders the current transformation coefficients and determinant directly on the canvas.

---

### 4. Interpolation, Envelopes & Easing
- **Smoothstep**: Cubic Hermite interpolation $S(x) = x^2(3 - 2x)$ eliminates abrupt acceleration across state changes and scroll boundaries.
- **Scroll Peak Window**:
  $$\text{peak}(\text{min}, \text{max}, S) = \begin{cases} S\left(\frac{S - \text{min}}{\text{mid} - \text{min}}\right) & S < \text{mid} \\ 1 - S\left(\frac{S - \text{mid}}{\text{max} - \text{mid}}\right) & S \ge \text{mid} \end{cases}$$
- **Linear Interpolation (LERP)**: Exponential smoothing $v \leftarrow v + (v_{\text{target}} - v) \cdot \alpha$ ensures smooth cursor tracking ($\alpha = 0.08$) and canvas collapse towards the footer ($\alpha = 0.04$).

## Technical Stack & Architecture

- **Zero Build Step**: Native ES6+ Modules (`type="module"`), no Webpack, Vite, or bundlers.
- **Pure Vanilla CSS**: CSS Custom Properties, CSS Grid, Flexbox, and glassmorphism (`backdrop-filter: blur(...)`).
- **Mathematical Rendering**: Client-side [KaTeX](https://katex.org/) for mathematical derivations in journal entries; HTML5 2D Canvas API for the 60 FPS background.
- **Modular File Layout**:
  ```
  portfolio/
  ├── index.html           # Main semantic markup
  ├── css/
  │   ├── main.css         # Central CSS manifest
  │   ├── variables.css    # Color tokens & typography
  │   ├── layout/          # Glassmorphism, nav, footer
  │   └── components/      # Hero, buttons, grid, credentials
  ├── js/
  │   ├── main.js          # App orchestrator
  │   └── modules/         # canvas.js, about.js, projects.js, etc.
  └── data/                # Decoupled JSON data files
  ```
